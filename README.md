# 산초 (Sancho) — 챗창 있는 대시보드, 두뇌는 내 Claude Code

산초는 **내 컴퓨터에서 도는 개인 AI 비서**입니다. 브라우저에서 산초와 채팅하면, 산초는 그 말을 이 컴퓨터에 설치된 **Claude Code**에 넘겨 일을 시키고 결과를 다시 화면에 보여줍니다.

- **API 키 없음.** Claude 구독으로 Claude Code 에 로그인만 하면 됩니다.
- **관문(게이트웨이)·클라우드 서버 없음.** 인터넷만 되면 노트북 어디서든 됩니다.
- **의존 패키지 0, 파일 2개**(server.js, public/index.html). 읽고 고치기 쉬운 크기입니다.

## 구조 한 장

```
브라우저 (채팅 + 대시보드)
   │  HTTP / SSE
   ▼
server.js  —  화면 · 시계(예약) · 기억 · 알림        ← 산초가 직접 하는 일은 이 넷뿐
   │  표준입출력  (claude -p --output-format stream-json)
   ▼
Claude Code (내 구독)  —  생각 · 도구 실행 (파일 읽기/쓰기, 웹 검색, 명령 …)
   │
   ▼
data/  =  산초의 기억 (전부 텍스트 파일)
   memory.md       기억            ← Claude 가 직접 한 줄씩 덧붙임
   schedule.json   예약            ← Claude 가 직접 항목 추가·삭제
   journal/        예약 실행 결과   ← 산초 서버가 날짜별로 쌓음
   history.jsonl   대화 기록
   settings.json   모델 · 권한
```

핵심 아이디어 하나: **도구를 따로 만들지 않습니다.**
"기억할 건 memory.md 에 적어라, 예약은 schedule.json 에 이런 형식으로 적어라"라고 시스템 프롬프트에 써 두면, Claude Code 의 파일 도구가 곧 산초의 도구가 됩니다. 산초 서버는 그 파일을 읽어 화면에 보여주고, 시간이 되면 예약을 Claude Code 에 보내 실행합니다.

## 설치 (5분, Windows / Mac 공통)

0. **Git** — https://git-scm.com (업데이트·복구에 씁니다). 그리고 산초 받기:
   ```
   git clone https://github.com/cwkim83/sancho_project.git Sancho
   ```
1. **Node.js 18 이상** — https://nodejs.org
2. **Claude Code** — https://code.claude.com/docs/en/quickstart 대로 설치한 뒤 터미널에서 `claude` 를 한 번 실행해 **본인 Claude 구독으로 로그인**합니다. (Pro 이상)
   - ⚠️ 데스크톱 앱(Claude 앱)에 로그인돼 있어도 **터미널의 `claude` 는 따로 로그인**해야 합니다. 확인은 `claude auth status` → `"loggedIn": true`.
   - 로그인이 안 돼 있으면 산초 채팅에 "Claude Code 에 로그인이 안 돼 있어요" 라고 뜹니다. 그때 터미널에서 `claude` → `/login`.
3. 이 폴더에서 **`sancho.bat`** 더블클릭 (Mac: 터미널에서 `node server.js`) → 브라우저가 http://127.0.0.1:8790 으로 열립니다.

## 사용

화면은 Claude 데스크톱 앱을 본떴습니다. 왼쪽에 대화 목록·예약·알림·기억, 가운데 대화, 아래 입력창에 권한·모델 선택과 전송 버튼.

- **채팅** — 그냥 말합니다. 산초가 생각하는 동안 전송 버튼이 **■** 로 바뀌고, 누르거나 **Esc** 를 치면 즉시 멈춥니다. 답은 마크다운으로 렌더링되고, 도구 사용은 ⏺ 줄로, 파일을 고쳤으면 "파일 N개 편집됨" 카드로 보입니다.
- **대화 목록** — "＋ 새 대화" 로 새로 시작하고, 왼쪽 목록에서 이전 대화를 누르면 그 대화를 이어갑니다(Claude Code 가 그 대화를 다시 불러옵니다). 기억·예약은 대화와 무관하게 유지됩니다.
- **기억** — "기억해: 나는 아침 6시에 일어난다" → memory.md 에 적히고 다음 대화부터 반영됩니다.
- **예약** — "매일 07:00 에 오늘 일정과 할 일을 정리해서 알려줘" → schedule.json 에 들어가고, 시간이 되면 실행돼 **알림** 패널에 결과가 뜹니다.
  - 컴퓨터가 꺼져 있어 놓친 예약은 켜지면 바로 1회 실행합니다.
  - 예약 옆 **지금** 버튼으로 바로 시험할 수 있습니다.
- **권한** — 입력창 왼쪽 "권한" 메뉴. 기본은 data/ 폴더만 읽고 씁니다. **명령 실행 허용**, **내 홈 폴더 접근 허용**, **자기 수정 허용**은 필요할 때만 켭니다.
- **모델** — 입력창 오른쪽 모델 메뉴. Sonnet(기본: 빠르고 한도 절약) / Opus(어려운 일) / Haiku(잡일).
- **업데이트·재시작** — 왼쪽 아래 ⚙ 메뉴.

## 자가 업그레이드

산초는 자기를 갱신하고, 허용하면 자기 코드도 고칩니다. 파이스와 다른 점은 **도구를 새로 만들지 않았다**는 것입니다. Claude Code 의 Edit 와 Bash 가 그대로 도구고, 산초가 만든 건 **안전장치**만입니다.

- **업데이트 버튼** — `git pull --ff-only` 로 GitHub 의 새 판을 받고, 관문을 지나면 재시작합니다. 관문에 걸리면 이전 판으로 되돌립니다.
- **관문** — 재시작 요청(`POST /api/restart`)이 오면 서버가 직접 `node --check server.js` 와 `node selftest.js` 를 돌립니다. 하나라도 실패하면 재시작을 거부하고 이유를 돌려줍니다. Claude 가 절차를 지키길 기대하지 않고 서버가 막습니다.
- **복구** — 정상 기동한 코드는 `git tag last-good` 으로 표시됩니다(작업 폴더가 깨끗할 때만). 서버가 비정상 종료하면 `sancho.bat` 이 last-good 으로 되돌리고 다시 켭니다. 세 번 연속 실패하면 멈추고 오류를 보여줍니다.
- **자기 수정 허용(설정)** — 켜면 Claude 에게 산초 코드 위치를 알려주고 산초 폴더를 열어줍니다. 기본은 꺼짐. 채팅으로 "산초야 보내기 버튼을 파란색으로 바꿔" 같은 걸 시킬 수 있습니다. Claude 는 고치기만 하고, **답이 끝나면 서버가** 바뀐 코드를 관문에 통과시켜 커밋하고 재시작합니다. 관문에 걸리면 변경을 버리고 이유를 채팅에 보여줍니다. (절차를 Claude 에게 맡겨 봤더니 "절차대로 해줘" 라고 해도 고치고 끝내더군요. 그래서 서버가 합니다.)

알아둘 것: 재시작·복구는 **`sancho.bat` 으로 켰을 때만** 됩니다(직접 `node server.js` 로 켰으면 재시작 요청은 그냥 꺼지는 것으로 끝납니다). 관문은 문법과 기본 흐름만 봅니다. 화면이 켜진 뒤 나는 실행 오류는 못 잡습니다.

## 알아둘 것

- Claude 구독의 **사용 한도(5시간 창)** 를 산초의 채팅과 예약이 같이 씁니다. 예약을 많이 걸면 한도가 빨리 찹니다.
- 산초는 **127.0.0.1 에만** 열립니다. 밖에서(휴대폰 등) 접속하려면 토큰 인증부터 붙이세요(다음 판).
- 데이터는 전부 data/ 안 텍스트 파일입니다. 백업은 폴더 복사, 초기화는 폴더 삭제.
- 이 방식(본인 PC + 본인 구독 + 진짜 Claude Code 실행)은 **본인이 쓰는 용도**입니다. 남에게 서비스로 제공하려면 Anthropic 문서상 API 키 방식을 써야 합니다.

## 파이스(PAIS)와 다른 점

| | 파이스 | 산초 |
|---|---|---|
| 두뇌 | omniroute 관문 → 여러 모델 | Claude Code 를 직접 실행 |
| 도구 | 66개를 직접 구현 | Claude Code 내장 도구 + 파일 규칙 |
| 코드 | 수천 줄 이상 | 약 360줄 (+ 자가시험 100줄) |
| 자기 수정 | 도구 4개로 직접 구현, 관문 없음 (사고의 원인이 되기도) | Claude Code 도구 그대로 + 관문(문법·자가시험) + last-good 자동 복구 |
