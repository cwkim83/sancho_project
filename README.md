# 산초 (Sancho) — 개인 AI 비서 + 업무 플랫폼, 두뇌는 내 Claude Code

산초는 **내 컴퓨터에서 도는 개인 AI 비서이자 업무 플랫폼**입니다. 브라우저에서 산초와 채팅하면, 산초는 그 말을 이 컴퓨터에 설치된 **Claude Code**에 넘겨 일을 시키고 결과를 다시 화면에 보여줍니다. 일정·프로젝트·메일·메신저·회의록·목표·결재 같은 업무 화면이 함께 붙어 있고, 그 화면들의 데이터도 산초에게 말로 시켜 만들고 고칠 수 있습니다.

- **API 키 없음.** Claude 구독으로 Claude Code 에 로그인만 하면 됩니다.
- **관문(게이트웨이)·클라우드 서버 없음.** 인터넷만 되면 노트북 어디서든 됩니다.
- **의존 패키지 0.** 서버는 파일 하나(server.js), 화면은 껍데기 한 장 + 메뉴별 화면 한 장씩입니다.
- **데이터베이스 서버 없음.** 모든 데이터가 `data/` 안의 JSON·마크다운 파일이라 열어 보고 고치고 백업하기 쉽습니다.

## 화면 (플랫폼)

왼쪽 메뉴는 업무 화면, **대시보드 자리는 산초 채팅**입니다.

| 메뉴 | 하는 일 |
|---|---|
| 대시보드 | 산초 채팅 — 인사말·오늘 요약 KPI·빠른 지시 버튼, 스트리밍 답, 파일 첨부·음성·🧠 뇌 그래프 |
| 일정 | 월/주 달력. 일정·업무 마감·목표 마일스톤·회의 예약·프로젝트 마감·산초 예약을 한 화면에 |
| 프로젝트 | 프로젝트 카드·연간 통합 간트·업무 칸반. 프로젝트를 누르면 WBS 공정표(EVMS·S곡선) |
| 메일정리 | 산초가 분류해 둔 메일을 긴급·업무·광고로 보고 처리·답장 초안·업무/일정 등록 |
| 메신저 | 공지·부서·프로젝트·그룹·1:1 채널. 산초도 대화 상대로 들어옵니다 |
| 회의실·회의록 | 주간 예약표, 음성 받아쓰기 녹취, 산초가 회의록으로 정리 |
| 목표관리 | 전사·부서·개인 OKR, 마일스톤 진척 |
| Manday | 한 줄 붙여넣기로 공수 기록·집계 |
| 조직/권한 · 관리 | 사람·부서·부서 도구함 구성, 산초 상태·실행 기록·데이터 점검 |
| 결재 | 기안·결재선·전결·반려, 인쇄 양식 |
| 로드맵·진척 | 단계별 항목 상태(대기/진행/완료/보류) |
| 지식노트 | 프로젝트·회의·결재·위키를 잇는 지식 지도 |
| 부서 도구함 | 부서별 실무 도구(ITP·QA 문서·NCR·CAR·측정기구·자산·교반기·압력용기 계산 등) |

모든 화면에 **`✳ 산초에게 시키기`** 버튼이 있습니다. 누르면 그 화면에 맞는 지시가 채팅창에 채워지고, 산초가 데이터 파일을 고치면 화면이 곧바로 따라 바뀝니다.

## 구조 한 장

```
브라우저
   껍데기 public/index.html  ─ 사이드바 · 헤더 · 산초 채팅
      └ iframe  public/m/<메뉴>.html      업무 화면   (public/m/sdb.js 로 저장소를 씀)
      └ iframe  public/m/tools/<도구>.html 부서 도구
   │  HTTP / SSE
   ▼
server.js  —  화면 · 저장소(/api/db) · 시계(예약) · 기억 · 알림
   │  표준입출력  (claude -p --output-format stream-json)
   ▼
Claude Code (내 구독)  —  생각 · 도구 실행 (파일 읽기/쓰기, 웹 검색, 명령 …)
   │
   ▼
data/  =  산초의 기억과 플랫폼 데이터 (전부 텍스트 파일)
   memory.md       기억            ← Claude 가 직접 한 줄씩 덧붙임
   schedule.json   예약            ← Claude 가 직접 항목 추가·삭제
   db/*.json       플랫폼 데이터    ← 화면도 쓰고 Claude 도 직접 고친다 (일정·프로젝트·메일·회의 …)
   wbs/*.json      공정표
   journal/        예약 실행 결과   ← 산초 서버가 날짜별로 쌓음
   파일함/          산초가 만든 문서 (엑셀·PPT·워드·PDF)
   history.jsonl   대화 기록
   settings.json   모델 · 권한 · 주인 정보
```

핵심 아이디어 하나: **도구를 따로 만들지 않습니다.**
"기억할 건 memory.md 에 적어라, 예약은 schedule.json 에 이런 형식으로 적어라, 일정은 db/events.json 에 이런 필드로 적어라"라고 시스템 프롬프트와 스킬에 써 두면, Claude Code 의 파일 도구가 곧 산초의 도구가 됩니다. 산초 서버는 그 파일을 읽어 화면에 보여주고, 시간이 되면 예약을 Claude Code 에 보내 실행합니다.

두 번째 아이디어: **화면과 두뇌가 같은 파일을 봅니다.** 업무 화면은 `/api/db` 로 `data/db/<컬렉션>.json` 을 읽고 쓰고, 산초(Claude)는 같은 파일을 직접 고칩니다. 서버가 파일 변화를 감시해 열려 있는 화면에 알려 주므로, 채팅으로 "내일 3시 회의 잡아줘" 하면 달력이 곧바로 바뀝니다. 컬렉션과 필드 규격은 `skills/platform/SKILL.md` 한 장에 정리돼 있고, 화면 쪽은 `public/m/sdb.js` 가 Firestore 와 같은 함수 이름(`collection·doc·getDocs·setDoc·onSnapshot` …)을 흉내 내므로 웹에서 흔한 코드를 거의 그대로 붙일 수 있습니다.

## 설치 (5분, Windows / Mac 공통)

0. **Git** — https://git-scm.com (업데이트·복구에 씁니다). 그리고 산초 받기:
   ```
   git clone https://github.com/cwkim83/sancho_project.git Sancho
   ```
1. **Node.js 18 이상** — https://nodejs.org
2. **Claude Code** — https://code.claude.com/docs/en/quickstart 대로 설치한 뒤 터미널에서 `claude` 를 한 번 실행해 **본인 Claude 구독으로 로그인**합니다. (Pro 이상)
   - ⚠️ 데스크톱 앱(Claude 앱)에 로그인돼 있어도 **터미널의 `claude` 는 따로 로그인**해야 합니다. 확인은 `claude auth status` → `"loggedIn": true`.
   - 로그인이 안 돼 있으면 산초 채팅에 "Claude Code 에 로그인이 안 돼 있어요" 라고 뜹니다. 그때 터미널에서 `claude` → `/login`.
3. 이 폴더에서 **`sancho.bat`** 더블클릭 (Mac: 터미널에서 `node server.js`) → 브라우저가 http://127.0.0.1:8790 으로 열립니다.
   - 처음 켤 때는 cmd 창이 보입니다(로그 확인용). 그 창을 닫으면 산초가 꺼집니다.
   - ⚙ → **Windows 시작 시 자동 실행** 을 켜면 컴퓨터를 켤 때 **창 없이 숨어서** 자동으로 켜집니다(시작 프로그램 폴더에 바로가기, 브라우저는 열지 않음). 숨어서 도는 산초를 끄는 방법은 ⚙ → **산초 끄기** 입니다.

## 사용

화면은 세종 플랫폼 v2 의 업무 화면 구성에 Claude 데스크톱 앱의 대화창을 합친 모양입니다. 왼쪽에 메뉴와 부서 도구함, 위에 검색·알림·설정·사용자, 대시보드 자리에 산초 채팅(대화 목록·예약·알림·기억은 채팅 왼쪽 칸).

**처음 할 일 두 가지**
1. 오른쪽 위 사용자 칩(주인 ▾)에 **이름·직급·부서·회사**를 넣습니다. 인사말·결재선·회의 참석자에 쓰입니다.
2. 왼쪽 **조직/권한**에서 사람과 부서를 정리하고, 부서마다 **부서 도구함에 보일 도구**를 고릅니다.

**업무 화면 쓰는 법** — 각 화면의 `+` 버튼으로 직접 넣어도 되고, `✳ 산초에게` 버튼이나 채팅으로 말해도 됩니다.
- "내일 오후 3시에 삼성전기 수압시험 입회 일정 잡아줘" → 일정
- "메일 정리해줘" → 메일정리 (연결된 앱 권한 필요)
- "WBS 만들어줘: 프로젝트 이름·대단락·기간" → 프로젝트 › 공정표
- "기안서 써줘: 비파괴검사 외주 420만원" → 결재
- "이번 분기 OKR 초안 짜줘" → 목표관리
- "오늘 공수 기록: SJ456 탱크 외관검사 8시간 야근 2" → Manday
- 회의 중 ⚙ → 회의록 녹취 → 끝내면 산초가 회의록으로 정리 → 회의실·회의록

- **채팅** — 그냥 말합니다. 산초가 생각하는 동안 전송 버튼이 **■** 로 바뀌고, 누르거나 **Esc** 를 치면 즉시 멈춥니다. 답은 마크다운으로 렌더링되고, 도구 사용은 ⏺ 줄로, 파일을 고쳤으면 "파일 N개 편집됨" 카드로 보입니다.
- **대화 목록** — "＋ 새 대화" 로 새로 시작하고, 왼쪽 목록에서 이전 대화를 누르면 그 대화를 이어갑니다(Claude Code 가 그 대화를 다시 불러옵니다). 기억·예약은 대화와 무관하게 유지됩니다.
- **기억** — "기억해: 나는 아침 6시에 일어난다" → memory.md 에 적히고 다음 대화부터 반영됩니다.
- **예약** — "매일 07:00 에 오늘 일정과 할 일을 정리해서 알려줘" → schedule.json 에 들어가고, 시간이 되면 실행돼 **알림** 패널에 결과가 뜹니다.
  - 컴퓨터가 꺼져 있어 놓친 예약은 켜지면 바로 1회 실행합니다.
  - 예약 옆 **지금** 버튼으로 바로 시험할 수 있습니다.
- **파일 첨부** — 입력창의 ＋, 또는 끌어다 놓기, 붙여넣기(Ctrl+V 로 화면 캡처도). 이미지는 미리보기가 뜨고 누르면 크게 봅니다. data/uploads/ 에 저장되고 Claude 가 Read 로 읽습니다(이미지·PDF 포함).
- **만든 파일** — Claude 가 엑셀·PPT·워드·PDF·이미지를 만들면(data/파일함/) 채팅에 파일 카드가 뜹니다. **보기**(이미지·PDF·글은 브라우저에서), **열기**(이 PC 의 엑셀·파워포인트로), **⬇**(내려받기). 문서 만들기 요령은 기본 스킬 `office-docs` 에 있고, Python 과 `openpyxl` `python-pptx` `python-docx` 가 필요합니다(없으면 Claude 가 설치를 제안합니다).
- **음성** — 🎤 를 누르고 말하면 말이 끊긴 뒤 자동으로 보내고 답을 읽어줍니다. ⚙ 에서 **"산초야" 호출 대기**를 켜면 마이크가 항상 열려 "산초야, 오늘 일정 알려줘" 처럼 부를 수 있습니다(파이스와 같은 방식, Chrome·Edge). **답 읽어주기**를 켜면 글로 물어도 읽어줍니다.
- **대화 목록** — 최근 5개가 보이고 "더 보기"로 전부 봅니다. 마우스를 올리면 📌 고정(3개까지, "고정됨" 칸에 항상 위)·✕ 삭제.
- **권한** — 입력창 왼쪽 "권한" 메뉴. 기본은 data/ 폴더만 읽고 씁니다. **명령 실행**, **내 홈 폴더 접근**, **연결된 앱**(claude.ai 에 연결한 Gmail·Google 캘린더·드라이브·Microsoft 365), **자기 수정**은 필요할 때만 켭니다.
- **모델·노력** — 입력창 오른쪽. 모델은 Fable 5.1 / Opus / Sonnet(기본) / Haiku. 노력은 Claude 앱처럼 5단계 슬라이더(더 빠르게 ↔ 더 스마트하게, `claude --effort`).
- **스킬** — "이거 스킬로 저장해" 하면 방금 한 절차가 data/.claude/skills/<이름>/SKILL.md 로 저장되고 다음 대화부터 Claude Code 가 자동으로 씁니다. "이 URL 의 SKILL.md 가져와" 도 됩니다(Hermes 의 스킬 가져오기와 같은 역할).
- **위키** — "조사한 내용 위키에 저장해" 하면 data/wiki/<주제>.md 에 쌓이고, 관련 질문에 먼저 참고합니다. 왼쪽에서 펼쳐 볼 수 있습니다.
- **배달** — 예약을 걸 때 "결과를 메일로 보내줘" 라고 하면 연결된 앱(Gmail)으로 보냅니다(권한 메뉴에서 켠 경우). 기본은 알림 패널에만 남습니다.
- **업데이트·재시작** — 왼쪽 아래 ⚙ 메뉴.
- **테마** — ⚙ 에서 자동(OS 따라)/밝게/어둡게. 답은 글자 단위로 흘러나옵니다(스트리밍).
- **🧠 뇌 그래프** — 제목줄의 🧠. 파이스의 코어 화면을 그대로 옮겨, 기억·위키·스킬·대화·예약이 하나의 그래프로 출렁입니다(ORB ↔ GRAPH 전환, 끌고 확대, 노드 클릭 미리보기). 헤더의 LED 는 산초가 생각할 때 깜빡입니다.
- **🎙 회의록** — ⚙ → "회의록 녹취 시작". 회의 중 말을 계속 받아쓰고, 끝내면 녹취를 첨부해 안건·결정·할 일 표와 워드 파일로 정리합니다.
- **연결 (선택, ⚙)** — 옵시디언 볼트 폴더("노트에 적어"), 텔레그램 봇(예약 결과를 휴대폰으로), 비상두뇌 Gemini 키(Claude 한도에 걸리면 도구 없이 대신 답), 외부 접속 토큰(터널로 밖에 열 때 — `SANCHO_HOST=0.0.0.0` 과 함께).
  - 옵시디언: 볼트 폴더를 넣으면 Claude 가 그 폴더를 읽고 씁니다(새 노트는 볼트 안 `산초/`). 볼트가 다른 컴퓨터에 있으면 이 PC 로 복사본을 두고 예약으로 한 방향 동기화하는 식으로 씁니다(부장님 PC: 맥 볼트 → `Documents\My-ai`, 매일 05:30). Obsidian 앱이 없어도 동작하고, 설치하면 "폴더를 볼트로 열기"로 같은 폴더를 열면 됩니다.
- **자동 기억** — 대화 중 알게 된 사실은 묻지 않아도 memory.md 에 쌓입니다("(기억함)" 표시).
- **WBS 공정표** — 세종 플랫폼의 WBS 모듈을 옮겼습니다. 채팅으로 "WBS 만들어줘: 프로젝트, 대단락, 작업, 기간", "용접 진도율 60%로" 하면 data/wbs/<프로젝트>.json 이 만들어지고 왼쪽 WBS 에 뜹니다. 누르면 공정표 화면: 코드·작업명(접기/펼치기)·담당·기간·가중치·진도율(계획 대비 색)·상태·간트(월 달력, 오늘선), 위에 EVMS 카드(진도율 EV·계획 PV·SV·SPI·지연 수), 아래 S-곡선. 상위·전체 진도율은 가중 합산이고 상태·지연은 자동입니다. 스냅샷 저장과 이력 복원, 인쇄 가능. 산초가 채팅으로 고치면 15초 안에 화면에 반영됩니다.

## 자가 업그레이드

산초는 자기를 갱신하고, 허용하면 자기 코드도 고칩니다. 파이스와 다른 점은 **도구를 새로 만들지 않았다**는 것입니다. Claude Code 의 Edit 와 Bash 가 그대로 도구고, 산초가 만든 건 **안전장치**만입니다.

- **업데이트 버튼** — `git pull --ff-only` 로 GitHub 의 새 판을 받고, 관문을 지나면 재시작합니다. 관문에 걸리면 이전 판으로 되돌립니다.
- **관문** — 재시작 요청(`POST /api/restart`)이 오면 서버가 직접 `node --check server.js` 와 `node selftest.js` 를 돌립니다. 하나라도 실패하면 재시작을 거부하고 이유를 돌려줍니다. Claude 가 절차를 지키길 기대하지 않고 서버가 막습니다.
- **복구** — 정상 기동한 코드는 `git tag last-good` 으로 표시됩니다(작업 폴더가 깨끗할 때만). 서버가 비정상 종료하면 `sancho.bat` 이 last-good 으로 되돌리고 다시 켭니다. 세 번 연속 실패하면 멈추고 오류를 보여줍니다.
- **자기 수정 허용(설정)** — 켜면 Claude 에게 산초 코드 위치를 알려주고 산초 폴더를 열어줍니다. 기본은 꺼짐. 채팅으로 "산초야 보내기 버튼을 파란색으로 바꿔" 같은 걸 시킬 수 있습니다. Claude 는 고치기만 하고, **답이 끝나면 서버가** 바뀐 코드를 관문에 통과시켜 커밋하고 재시작합니다. 관문에 걸리면 변경을 버리고 이유를 채팅에 보여줍니다. (절차를 Claude 에게 맡겨 봤더니 "절차대로 해줘" 라고 해도 고치고 끝내더군요. 그래서 서버가 합니다.)

알아둘 것: 재시작·복구는 **`sancho.bat` 으로 켰을 때만** 됩니다(직접 `node server.js` 로 켰으면 재시작 요청은 그냥 꺼지는 것으로 끝납니다). 관문은 문법과 기본 흐름만 봅니다. 화면이 켜진 뒤 나는 실행 오류는 못 잡습니다.

## 알아둘 것

- Claude 구독의 **사용 한도(5시간 창)** 를 산초의 채팅과 예약이 같이 씁니다. 예약을 많이 걸면 한도가 빨리 찹니다.
- 산초는 **127.0.0.1 에만** 열립니다. 밖에서(휴대폰 등) 접속하려면 토큰 인증부터 붙이세요(다음 판).
- 데이터는 전부 data/ 안 텍스트 파일입니다. 백업은 폴더 복사, 초기화는 폴더 삭제.
- 이 방식(본인 PC + 본인 구독 + 진짜 Claude Code 실행)은 **본인이 쓰는 용도**입니다. 남에게 서비스로 제공하려면 Anthropic 문서상 API 키 방식을 써야 합니다.
