# WBS(공정표)

## 파일
산초 데이터 폴더 안 **`wbs/<프로젝트>.json`** 하나가 공정표 하나다(없으면 만든다). 대시보드 왼쪽 "WBS" 에 자동으로 뜨고, 진도율 합산·계획 대비·간트는 화면이 그린다 — 너는 파일만 정확히 쓰면 된다.

```json
{
  "name": "PK-5260 제독설비 제작",
  "no": "2026-031",
  "items": [
    { "code": "1",   "name": "자재 입고",     "lv": 0, "mgr": "구매부", "weight": 20, "memo": "" },
    { "code": "1.1", "name": "강판 입고",     "lv": 1, "mgr": "김철우", "s": "2026-09-01", "e": "2026-09-10", "pct": 100 },
    { "code": "1.2", "name": "파이프 입고",   "lv": 1, "mgr": "김철우", "s": "2026-09-05", "e": "2026-09-20", "pct": 40 },
    { "code": "2",   "name": "제작",         "lv": 0, "mgr": "생산부", "weight": 60 },
    { "code": "2.1", "name": "절단·성형",     "lv": 1, "s": "2026-09-15", "e": "2026-10-05", "pct": 0 },
    { "code": "2.2", "name": "용접",         "lv": 1, "s": "2026-10-01", "e": "2026-10-31", "pct": 0 },
    { "code": "3",   "name": "검사·출하",     "lv": 0, "mgr": "품질관리부", "weight": 20 },
    { "code": "3.1", "name": "수압시험",      "lv": 1, "s": "2026-11-01", "e": "2026-11-05", "pct": 0 },
    { "code": "3.2", "name": "도장·포장·출하", "lv": 1, "s": "2026-11-06", "e": "2026-11-15", "pct": 0 }
  ]
}
```

## 규칙
- **순서가 계층이다.** 항목은 나열 순서대로 그려지고, 자식은 부모 바로 뒤에 `lv` 를 1 크게 두어 나타낸다(대단락 0 · 작업 1 · 세부 2). 코드는 `1`, `1.1`, `1.1.1` 식으로 순서에 맞게 다시 매긴다.
- **날짜는 `YYYY-MM-DD`**, 말단 작업에 `s`(시작)·`e`(완료)를 적는다. 상위 항목의 기간은 후손에서 자동으로 잡히니 비워도 된다.
- **가중치 `weight` 는 대단락(lv 0)에** 적고 합이 100이 되게 한다(없으면 균등). 작업(lv 1)끼리도 비중이 다르면 적을 수 있다.
- **진도율 `pct` 는 말단 작업에만** 적는다(0~100). 상위·전체는 가중 평균으로 자동 합산된다. 상태(미시작·진행중·완료·지연)도 자동이다 — 완료일이 지났는데 100 이 아니면 지연.
- 주인이 "○○ 진도율 60%" 하면 그 항목의 `pct` 만 고친다. "○○ 끝났어" 는 100. 날짜를 바꾸면 `s`/`e` 를 고친다.
- 크게 고치기 전(항목 여러 개 삭제·재배치)에는 `curl -s -X POST http://127.0.0.1:8790/api/wbs/snapshot -H "content-type: application/json" -d "{\"name\":\"<프로젝트>\"}"` 로 이력을 남긴다(명령 실행 권한이 있을 때). 주인은 WBS 화면의 "이력" 에서 되돌릴 수 있다.
- 고친 뒤엔 무엇을 바꿨는지 한 줄 + "왼쪽 WBS 에서 보세요" 라고 알린다. 엑셀로 달라고 하면 이 JSON 을 읽어 office-docs 스킬로 만든다(코드·작업명·담당·시작·완료·가중치·진도율·상태).
- 지연·현황 질문("뭐가 늦었어")엔 `GET http://127.0.0.1:8790/api/wbs?name=<프로젝트>` 의 결과(rows 의 status·diff, 전체 pv·ev·spi)를 읽어 답한다 — 직접 계산하지 않는다.
